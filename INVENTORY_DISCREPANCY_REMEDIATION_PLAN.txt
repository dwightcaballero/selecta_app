          matched to how they're actually used:

     (time-in/out records; any authenticated staff member reads/writes their
     own flow today per attendance_service.dart - confirm no per-user scoping

                                            allow create: if isDealerOrAdmin();

     (append-only audit history, mirrors inventory_movements style)

   - match /van_loads/{loadId}           { allow read, write: if isStaff(); }

     (admin_promos_page.dart is an admin management screen; store/dealer
     apps only need read access to active promos)
